# GPT 그림 원본 모음

GPT에서 **다운로드한 원본 PNG**를 여기에 올림 (GitHub 웹: `test` 브랜치 → 이 폴더 → Add file → Upload files). 게임에 넣을 때 Claude가 게임용 그림으로 바꿈 (프롬프트: `docs/ART_PROMPTS.md`)

## 폴더 (이름 = 한글 이름, 소품·이펙트는 그 주인 폴더에)

| 폴더 | 들어가는 것 |
| --- | --- |
| `캐릭터/{캐릭터 이름}/` | 캐릭터 그림 시트 · 스킬 이펙트 · 무기 · 변신 모습 (예: `캐릭터/루나틱/`, 변희 동물은 `캐릭터/변희/`) |
| `일반보스/{보스 이름}/` | 1~3단계 층 보스와 그 보스 소품 (예: `일반보스/지옥문 수문장/` 지옥문·임프) |
| `최종보스/{보스 이름}/` | 라스트 보스와 그 소품 |
| `몬스터/{몬스터 이름}/` | 일반 몬스터 |
| `방/{방 이름}/` | 특별한 방 소품·NPC (경매장·도박꾼·악마·비밀·시련·제단의 방·대장장이) |

- 새 그림은 위 폴더 중 맞는 곳에 이름 폴더를 만들어 올림 (모르면 `art/` 바로 아래에 올려도 Claude가 옮김)
- 예전 그림 중 `scripts/art/src/`(변환 도구가 읽는 영문 이름 사본, 예 `warden-1.png`)에만 있던 것도 이 폴더에 같은 이름으로 복사해 둠 (같은 그림이라 저장소 용량은 늘지 않음)
