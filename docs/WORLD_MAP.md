# 세계 지도·스토리 진행 계획 (초안)

> 작성 2026-11-13 (한국 시간) · 상태: 걸어 다니는 지도로 결정 · W1 ✅ 0.52.78 · W2 ✅ 0.52.79 · W3부터 ⬜

## 1. 왜 하나 — "게임이 어지럽다"

- 메인 화면 버튼 7개 + 아래 줄 5개 + 이벤트 안에 또 여러 모드(패왕전·레이드·타워 디펜스·광야의 새벽 등) + 로비·미니 게임이 **처음부터 한꺼번에** 보인다
- 캐릭터가 12개 진영에 100명 넘게 있어, 처음 온 사람은 누가 누군지·무엇부터 할지 모른다
- 스토리(아카식 레코드 1~9장)는 이미 있는데 '아카이브 → 스토리'에 숨어 있어 읽는 사람만 읽는다

**바꾸는 방향**: 스토리를 따라 세계 지도를 걸어가며 나라를 하나씩 열고, 나라를 열 때마다 그 나라 캐릭터·모드가 열린다. 처음에는 "혼자 하기 + 지도"만 보인다.

## 2. 큰 지도, 만들 수 있나 → **가능합니다**

막히는 것은 기술이 아니라 **그림·내용의 양**입니다. 이유:

| 걱정 | 답 |
| --- | --- |
| 지도가 크면 느려지지 않나 | 화면에 보이는 칸만 그린다(로비·던전이 이미 카메라로 그렇게 함). 32×32칸 덩어리로 미리 그려 두고, 화면 근처 덩어리만 메모리에 둠 → 지도 크기와 상관없이 같은 속도 |
| 지도 데이터가 파일 300줄·14KB 규칙에 걸리지 않나 | 지도 모양은 코드가 아니라 **그림 파일(PNG, 1픽셀 = 1칸, 색 = 땅 종류)**로 `public/`에 둔다. 나라마다 한 장. 물건·입구·NPC 자리만 작은 표(나라마다 파일 하나) |
| 다운로드가 무겁지 않나 | 320×200칸 지도 PNG는 수십 KB. 나라 지도는 그 나라에 들어갈 때 받는다(`lazyImage` 방식) |
| 서버 비용 | **0에 가깝다**. 지도 걷기는 화면에서만 계산. 진행(연 나라·장)은 값이 바뀔 때만 기존 클라우드 저장에 함께 넣음 |
| 휴대폰 | 로비와 같은 조작(터치 이동). 덩어리 캐시 수를 줄여 메모리 아낌 |

### 크기 예시 (조정 가능)

- 한 칸 16px, 화면 하나 ≈ 21×13칸 (지금 로비 크기)
- **나라 하나 ≈ 64×40칸** (화면 3×3장쯤): 마을(거점) + 던전 입구 2~3곳 + 길
- **세계 전체 ≈ 320×200칸** (화면 15×15장쯤) — 끝에서 끝까지 걸으면 2~3분 → **빠른 이동 필수**: 연 마을끼리 순간 이동, 바다는 월계선(이미 있는 배 그림)으로

## 3. 지도 짜임 — 3층 구조 (추천)

1. **세계 지도** (줌 아웃, 큰 그림 한 장): 나라 경계·이름. 안 연 나라는 안개로 가림. 누르면 연 마을로 빠른 이동
2. **나라 필드** (걸어 다니는 지도): 마을·길·던전 입구·표지판·NPC. 이야기 대사가 여기서 나옴
3. **던전** (지금 있는 한 판): 입구에 들어가면 **지금 게임 그대로** 시작. 그 나라 층 테마·보스로

→ 전투 규칙(`sim/`)은 거의 안 건드림. 새로 만드는 것은 "걷는 지도 + 진행 저장 + 해금 연결"이라 기존 시드 결정성·서버 검사와 부딪히지 않음.

## 5. 스토리 진행 = 해금 순서 (초안)

장마다 "그 장에 나오는 나라·인물"을 연다. 장의 등장인물은 `story/storyData`의 `CHAPTERS`를 그대로 씀.

| 장 | 여는 나라 | 여는 모드 (예) |
| --- | --- | --- |
| 프롤로그 | 아스칼론 마을 하나 | 혼자 하기(기본 캐릭터 몇 명)만 |
| 1장 | 아스칼론·비르디아 | 일일 도전 |
| 2장 | 테라코어 | 같이 하기(배틀) · 협동 |
| 3장 | 헬리오스 | 이벤트(광야·타워 디펜스) · 상점 |
| 4~6장 (시즌 2) | 각 나라 2막 · 최종 보스 | 영웅 모드·끝없는 탑·아레나 · 레이드 |
| 7장 | 새벽의 성흔·아슈바르 균열 | 패왕전 |
| 8장 | 성국 | — |
| 9장 | 탈라시아·실베르 | 금기 등 고급 모드 |

- 장을 여는 조건: 그 나라 던전(그 장 보스) 클리어 → 마을에서 이야기 장면 → 다음 길이 열림
- **캐릭터 해금**: 나라를 열면 그 나라 캐릭터가 "얻을 수 있음"이 되고, 지금 해금 조건(최대 체력 250 달성 등)은 그대로 둠 — 나라를 안 열었으면 선택 화면에 아예 안 보임(어지러움 줄이기의 핵심)
- 메인 화면 버튼도 연 모드만 보임. 잠긴 버튼은 숨김(또는 "○장에서 열림" 한 줄)

## 6. 이미 하던 사람은?

- 기록(점수·업적·해금 캐릭터)이 있는 사람은 **처음 들어올 때 모든 나라·모드를 연 채로** 시작 (지금 하던 것이 사라지지 않게)
- 설정에 "스토리 순서 무시하고 모두 열기"를 둘지 → 🔸 정할 것
- 일일 도전·배틀·패왕전 순위 등 서버 기록은 그대로
