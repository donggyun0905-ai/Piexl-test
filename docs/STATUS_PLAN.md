# 상태이상 공통 규칙 추천안 (계획서)

> 작성 2026-10-31 (한국 시간). 지금 상태는 `docs/STATUS.md`. 이 문서는 **추천안**이고 코드는 아직 그대로.
> 마음에 안 드는 줄은 고치거나 지워서, 항목마다 **✏️** 칸에 적어 주시면 그대로 반영함.

## 왜 바꾸나

- 지금은 같은 '독'이라도 캐릭터마다 지속 시간·피해 계산·쌓이는 방식이 다 다름 → 아이템 설명·밸런스 조정이 어려움
- 상태이상마다 **개성(무엇을 잘하는지)** 을 하나씩 정하고, 계산은 공통 틀 하나로 맞춤
- 캐릭터마다 다른 건 **세기 배율 하나**만 남김 (예: 사멸 독 ×1.2, 플라이 독 ×0.8)

## 공통 틀

| 항목 | 추천 |
| --- | --- |
| 피해 간격 | 모든 지속 피해 0.5초 (지금과 같음) |
| 피해 기준 | 거는 사람의 공격력 × 상태이상 기본 비율 × 캐릭터 세기 배율 × 상태이상 강화(기본 스탯) |
| 다시 걸면 | 시간은 처음부터 · 세기는 더 센 쪽 (쌓이는 종류만 중첩 +1) |
| 보스 | 기절·빙결 시간 1/3 · 즉사 없음 · 체력 비례 피해는 상한 있음 |
| 머리 위 표시 | 걸린 상태이상 아이콘 + 중첩 숫자 (지금은 피해 숫자 옆에만) |
| 관리자 | 상태이상마다 **전체 배율 · 보스 배율 · 지속 시간 · 최대 중첩** 4칸 (STATUS_RULES 한곳에) |

## 지속 피해

### 출혈 — "쌓을수록 아픔"
- 3초 · 0.5초마다 공격력의 8% × 중첩 · 최대 5중첩 (5중첩이면 0.5초마다 40%)
- 적이 움직이는 중이면 피해 1.5배 (도망치는 적에게 강함)

✏️ 바꿀 내용:

### 화상 — "짧고 강함"
- 2초 · 0.5초마다 공격력의 25% (2초에 공격력 100%, 지금과 같음) · 쌓이지 않음 (더 센 쪽)
- 서리·빙결과 함께 걸리면 둘 다 풀리고 화상 피해 한 번 2배 (녹임)

✏️ 바꿀 내용:

### 독 — "길게, 많이"
- 5초 · 0.5초마다 공격력의 6% × 중첩 · 최대 8중첩
- 보스에게도 그대로 (보스 잡기용)

✏️ 바꿀 내용:

### 지옥불 — "화상의 상위"
- 3초 · 0.5초마다 공격력의 25% + 적 최대 체력의 0.5% (보스는 체력 비례 없음)
- 물결·서리로 꺼지지 않음 · 악의 사도 전용

✏️ 바꿀 내용:

## 약화

### 부식 — "받는 피해 증가"
- 4초 · 중첩당 받는 피해 +3% · 최대 10중첩 (+30%) · 자체 피해 없음
- 지금의 '장갑 용해'(기계공학자)와 역병의사 방어 깎기를 이걸로 합침

✏️ 바꿀 내용:

### 서리 — "느리게, 그러다 얼림"
- 2초 동안 느림 30% · 3중첩이면 빙결(기절) 1.5초 (보스 0.5초) · 빙결 뒤 3초 동안 다시 안 얼음
- 서리 자체 피해는 작게 (공격력의 20% 한 번)

✏️ 바꿀 내용:

### 물결 — "젖음, 다른 상태이상과 연계"
- 4초 동안 젖음: 느림 10% · 감전 피해 1.5배 · 서리 중첩 +1 더 · 화상 시간 절반
- 해일(오니 등)은 한 방 공격력 50% + 밀침

✏️ 바꿀 내용:

## 쌓아서 터뜨림

### 저주 — "3번 쌓으면 폭발"
- 6초 안에 3중첩 → 공격력 150% 한 번 + 주변에 절반 · 6초 안에 못 채우면 사라짐
- 음양사 봉인·오니 야마타를 이 규칙으로

✏️ 바꿀 내용:

### 죽음 — "시간이 다 되면 큰 피해"
- 4초 표식 → 끝날 때 공격력 200% · 일반 적이 그때 체력 15% 이하면 즉사 (보스는 즉사 없이 피해만)
- 사멸·역병의사·악의 사도·학살자의 '죽음'을 이 규칙으로

## 바꾸는 순서 (정해 주시면 진행)

1. 관리자 STATUS_RULES에 상태이상마다 전체 배율·보스 배율·시간·최대 중첩 칸 만들기 (게임은 그대로, 배율 1)
2. 상태이상 하나씩 공통 틀로 옮기기 (지속 피해 → 약화 → 쌓아서 터뜨림 → 한 방 추가 순)
3. 옮길 때마다 캐릭터별 세기 배율을 맞춰 지금 세기와 비슷하게 시작 → 연습장에서 비교
4. 아이템·캐릭터 설명 글자(한·영·일) 숫자 고치기 · 패치 노트

- 주의: 2~3번은 게임 계산이 바뀌는 큰 작업이라 캐릭터 세기가 달라질 수 있음 (특히 오니·악의 사도·역병의사·사멸·원소술사처럼 상태이상을 많이 쓰는 캐릭터)
