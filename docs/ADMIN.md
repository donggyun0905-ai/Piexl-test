# 관리자 페이지 (게임 수치 조정)

> 설계 요약은 `docs/PLAN.md` 8장 '관리자 페이지'. 이 문서는 켜는 방법과 쓰는 방법.

## 주소

| 서버 | 관리자 페이지 | 게임 서버 (Worker) |
| --- | --- | --- |
| 라이브 (main) | `pixel-rogue.pages.dev/admin/` | `pixel-rogue` |
| 디벨롭 (develop) | `develop.pixel-rogue.pages.dev/admin/` | `pixel-rogue-beta` |
| 테스트 (test) | `test.pixel-rogue-test.pages.dev/admin/` | `pixel-rogue-test` (`pixel-rogue-test.donggyun0905.workers.dev`) |

- 각 주소의 관리자 페이지는 **그 서버만** 다룸 (다른 서버는 보이지 않음, 로그인도 서버마다 따로). 관리자 요청은 그 서버의 화면 주소에서만 받음
- test는 놀이터 서버라 따로 관리: 다른 서버 수치 가져오기 기능이 없음 (라이브·디벨롭도 test 수치는 가져오지 않음)

## 켜기 (서버마다 한 번, 사용자가 직접)

1. 디스코드: 코드를 받을 **비공개 채널** → 채널 설정(톱니) → 연동 → 웹후크 → 새 웹후크 → '웹후크 URL 복사'
   - 세 서버가 같은 채널을 써도 됨 (글에 `[live]`·`[beta]`·`[test]`가 붙어 구분됨)
2. Cloudflare 대시보드 → Workers 및 Pages → 해당 Worker(`pixel-rogue-beta` 등) → 설정 → 변수 및 비밀 → 추가
   - 유형: **비밀(Secret)** · 이름: `ADMIN_LOGIN_WEBHOOK` · 값: 복사한 웹후크 URL → 배포
   - 비밀은 GitHub Actions 배포 때 지워지지 않음. 채팅·코드·저장소에 붙여 넣지 않기
3. 없으면 그 서버의 관리자 기능은 꺼져 있음 (페이지에 '웹훅이 없습니다' 안내)

## 쓰기

- 로그인: '디스코드로 코드 받기' → 채널에 온 8자 코드 입력 (5분 유효, 30초에 한 번만 요청) → 12시간 로그인
- 캐릭터·무기·규칙·기술 수치·아이템 효과·적·보스·패시브·사용 아이템·상점 가격 탭: 칸을 고치고 아래 '저장'.
  - 캐릭터·무기·규칙·기술 수치·아이템 효과는 **표 안의 숫자를 자동으로 모두** 보여 줌 (무기 모양 안의 미사일 수·확률, 캐릭터마다 계산 파일의 수치까지). 위쪽 찾기 칸(이름·값 이름)과 분류(캐릭터) 고르기로 좁힘
  - 범위는 처음 값으로 자동: 확률 0~1, 그 밖은 처음 값의 5배까지 (정수 값은 정수)
  - '적'·'보스' 탭: 적 표의 숫자 모두 + 기술 수치 (보스는 계산 파일의 BOSS_* 묶음: 용 브레스 빠르기·운석 반경 등, 적은 ENEMIES·MINIONS·CRITTERS·HAZARDS 묶음). 위쪽 '몬스터·보스 그림 고치기'는 도트 편집 페이지(`/pixel/`)의 몬스터 묶음 (고친 그림은 그 기기에서 바로 써 보고, PNG로 받아 저장소 `public/sprites/custom/`에 넣으면 모두에게)
  - '상태이상' 탭: 독·화상·출혈·부식·죽음·물/빙결·감전·기절/느림·예리함에 쓰이는 값만 모든 묶음에서 모아 보여 줌 (값 이름에 그 낱말이 있는 것). 바꾸면 원래 묶음의 값이 바뀜 (화상 지속·피해 간격은 '규칙'의 STATUS_RULES, 부식은 COMBAT_RULES.MELT_ADD)
  - '캐릭터'에는 모든 캐릭터 공통 추가 기본 스탯도 있음 (처음엔 0): 치명타 확률·치명타 피해(150%) · 방어력(받는 피해 100/(100+방어력)) · 피해 감소 · 회피 · 재생력(10초마다) · 흡혈 · 예리함(맞힐 때 확률로 적이 받는 피해 +25%·출혈) · 상태이상 강화 · 돈 획득. 값이 있으면 게임 능력치 창에도 보임 노란 칸 = 처음 값과 다름, ↺ = 처음 값으로. 칸에 마우스를 올리면 처음 값·범위
- 저장하면 새로 시작하는 판부터 적용 (진행 중인 판은 그대로. 화면은 앱을 열 때·판이 끝날 때 새 수치를 받음, 최대 30초 늦을 수 있음)
- 바꾼 기록: 최근 30번. '되돌리기'로 그때 수치로 다시 저장
- **위쪽 '던전 수치 / 타워 디펜스 수치'**: 타워 디펜스 수치는 따로 (주소 `/admin/?td`). 던전과 섞이지 않고 서버에도 따로 저장·기록 (`/api/balance?set=td`)
  - 규칙·돈(목숨·시작 돈·타워 값·레벨 비용·라운드 보상·적 체력이 느는 정도·일반 적 수 배율·빠져나갈 때 잃는 목숨·최종 보스 빠르기) · 타워(캐릭터) 보정(공격력·공격 속도·사거리 배율) · 적(체력·빠르기·돈·크기·방패) · 보스(체력·빠르기·돈·크기, 최종 보스는 체력 그대로) · 보스 라운드(보스 체력 배율·간격)
  - 연습장: 맵을 골라 저장 전 수치로 바로 해 봄
- **위쪽 '클리어 시간'** (0.48.78): 캐릭터마다 유저들이 혼자 하기 6층을 처음 깨는 데 걸린 평균·가장 빠른 시간·클리어 수 (금기·무작위 시작 장비·무한·영웅의 길·아레나·서든데스 제외, 평균이 짧은 순)

## 코드

- 공용: `packages/shared/src/balance.ts` (넣기·다듬기·지문·비교) · `balanceFields.ts` (바꿀 수 있는 값 목록과 범위. 새 묶음은 여기 추가) · `balanceAuto.ts` (표 안 숫자 자동 찾기·범위) · `balanceTables.ts` (규칙·아이템 효과 표 모음: 새 무기·아이템 파일은 여기 한 줄) · `sim/rulesRegistry.ts` (계산 파일의 수치 묶음 `*_RULES` 모음) · `tdBalanceFields.ts` (타워 디펜스 값 목록) · `tdDefs.ts` (타워 디펜스 수치 표) · `perks.ts` (효과 패시브·상점 가격 수치 표)
- 서버: `apps/server/src/adminLogin.ts` (디스코드 코드 로그인) · `balanceApi.ts` (저장·지문별 수치·기록) · `clearStats.ts` (캐릭터별 클리어 시간 모으기)
- 화면: `apps/client/src/balance.ts` (받기·판 시작 때 넣기, 일일·레이드·아레나 제출에 지문) · `apps/client/src/admin/` (관리자 페이지: `AdminApp` 위쪽·던전/타워 디펜스 고르기 · `autoLabels` 자동 수치 이름·분류 · `BalanceAdmin` 수치 세트 하나 · `ClearStats` 캐릭터별 클리어 시간 표 · `TdPreview` 타워 디펜스 연습장) · `apps/client/admin/index.html`
