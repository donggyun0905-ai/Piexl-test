# 패왕전 스킬 개편 설계표 (초안)

마지막 수정: 2026-10-28 (한국 시간)

패왕전에서 무기·패시브 고르기를 없애고, 모든 캐릭터(히든 6명 뺀 42명)를 **평타 · 패시브 · 스킬 1~4**로 통일합니다.
**패왕전 전용**: 패왕전 판에서만 이 스킬 세트를 쓰고, 일반 던전·다른 모드는 스킬화하지 않고 지금 그대로입니다.

## 1. 공통 규칙

### 조작
| 키 | 내용 |
| --- | --- |
| 마우스 왼쪽 | 평타 (캐릭터 기본 무기) |
| 1 · 2 · 3 | 일반 스킬 (짧은 재사용 대기) |
| 4 | 궁극기 (긴 재사용 대기, 일부는 게이지가 차야 사용) |
| 대시 · Q/E | 지금 그대로 (대시 · 사용 아이템) |

- **시전 방식 (기본)**: 스킬 키를 누르면 사거리 원·범위 미리보기가 뜨고, 마우스로 원하는 곳을 **클릭하면 시전**. 다시 누르거나 오른쪽 클릭이면 취소
- **바로 사용 (설정)**: 스킬마다 켤 수 있음. 켜면 키를 누르는 순간 마우스 위치로 바로 시전
- **키 바꾸기**: 설정의 조작키에서 1·2·3·4를 다른 키로 (추적자 스킬 키처럼)
- **모바일**: 스킬 버튼 4개. 누른 채 끌어 조준하고 떼면 시전 (짧게 누르면 바로 사용)
- **화면**: 아래쪽에 스킬 칸 4개(아이콘·남은 초·게이지형은 게이지). 마우스를 올리면 설명

### 스킬 모양 (공통 틀)
모든 스킬은 아래 모양 중 하나로 만들고, 이펙트는 **그 캐릭터의 기존 무기 이펙트를 다시 씀** (이미 있는 공격 그림·소리를 크게·한 번에).

| 모양 | 설명 |
| --- | --- |
| 지점 | 마우스 위치에 원 범위 (바로 또는 잠시 뒤 터짐 · 바닥에 예고 원) |
| 직선 | 마우스 방향으로 탄·빔·찌르기 (관통 여부) |
| 부채꼴 | 앞쪽 부채꼴 |
| 돌진 | 마우스 위치까지 이동하며 지나간 적을 때림 |
| 순간이동 | 마우스 위치(또는 맞은 적 뒤)로 바로 이동 |
| 자신 | 내 둘레 원 · 버프 · 막기 |
| 소환 | 정해진 시간 동안 함께 싸우는 것 |

### 상태이상 (패왕전 공통)
기절 · 둔화 · 속박(못 움직임, 공격은 가능) · 밀치기 · 끌어오기 · 침묵(스킬 못 씀)
- 같은 사람이 3초 안에 다시 기절·속박되면 시간이 반으로 (계속 묶여 아무것도 못 하는 일 방지)

### 평타·패시브
- 패시브는 그 캐릭터의 지금 핵심 능력(게이지·스택·펫 등)을 그대로 살림. 게이지는 체력 줄 아래 작은 줄로 표시
- **게이지형·평타형 캐릭터는 평타 피해 +10~20%** (표의 '평타'에 적음)
- 수치는 공격력 대비 % · 재사용 대기는 초. **모두 처음 값이고 시험해 보며 관리자 페이지에서 조정**

### 준비방
- 무기·패시브 고르기 없앰 → 캐릭터만 고름 (사용 아이템은 경기장에서 줍기, 수정 사항 3번)
- 상대가 고른 캐릭터·스킬·패시브를 모두 볼 수 있음 (수정 사항 17번 밴픽 창에서)
