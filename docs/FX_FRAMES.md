# 효과 그림 칸(프레임) 넘기기 규칙

2026-11-13 사용자 지시. 효과 시트 그림이 칸 4개뿐이어도 끊기지 않고 여러 칸인 것처럼 보이게 한다.

## 규칙

- **짧은 효과**(한 번 치고 끝): 0 → 1 → 2 → 3칸을 차례로, 다음 칸과 겹쳐 부드럽게 넘긴다.
- **오래 가는 효과**(여러 대 때리느라 이펙트를 더 유지해야 할 때): 마지막 칸에서 멈춰 있지 않는다.
  1. 처음: 0칸부터 반복 첫 칸까지 차례로
  2. 가운데: 칸 몇 개를 **반복**한다 (보통 1·2칸, 그림에 맞게 고름: 마지막 칸과 그 좌우 반전 · 회전 · 낙뢰처럼 한 대마다 다시 치기)
  3. 끝: **마지막 한 대가 들어가는 때에 맞춰** 마지막 칸을 띄우고 끝낸다
- 두 칸을 겹칠 때 둘 다 밝게 유지한다 (가운데서 어두워지면 깜빡여 끊겨 보임).
- 좌우 반전하면 방향이 뒤집히는 그림(빔·직선 공격)은 반전하지 않는다.
- 방향이 있는 그림은 바라보는 쪽(또는 돌진 쪽)으로 돌린다. 캐릭터가 따라가야 하는 그림(예: 지그재그 길)은 그림 속 자리를 재서 계산(sim)의 길과 맞춘다.
- 맨 끝 5틱만 흐리게 해서 마지막 칸이 다 보이게 한다.

## 코드

- 화면: `apps/client/src/game/render/sheetLoop.ts`의 `sheetLoop(ctx, pic, row, ticks, maxTicks, x, y, w, a, 회전, 뒤집기, 반복칸, 칸당 틱)`
  - 32틱보다 짧으면 차례대로, 길면 반복
  - 끝 `OUTRO`(10틱)는 마지막 칸
  - 효과마다 반복 칸은 각 캐릭터 `*Fx.ts`의 `LOOP` 표에 둔다
- 계산(sim): 효과 길이(`maxTicks`)는 마지막 한 대 뒤 약 10틱으로 정한다
  - 예: 존 `sim/jaune.fxLen(대 수, 간격, 처음 지연)`
  - 끝 한 방(강타)이 있으면 그 한 방이 맨 마지막에 오도록 간격을 맞춘다

## 화면으로 찍어서 보며 맞추기 (필수)

새 효과를 넣거나 고치면 **반드시 스크린샷으로 시간대별 모습을 보고** 끊김·크기·회전·자리를 맞춘다.

1. `cd apps/client && npx vite --port 5199` (개발 서버)
2. `node scripts/fxshot.cjs '<행 JSON>' '<지난 틱 JSON>' 저장.png ticks`를 실행한다. 예:
   ```
   node scripts/fxshot.cjs '[{"kind":"jnHand","max":70,"size":40},{"kind":"jnStep","max":82,"size":200,"zig":true}]' '[0,4,8,12,20,30,40,50,60,66]' /tmp/a.png ticks
   ```
   - 행: `kind` · `max`(maxTicks) · `size` · `dir`([x,y]) · `style` · `zig`(존 돌진 길을 초록 선으로)
   - 화면: `apps/client/fxprev/` (개발용, 게임 빌드에 안 들어감)
3. 이웃한 틱 사이에 그림이 사라지거나, 어두워지거나, 크게 바뀌면 반복 칸·겹치기를 고친다. 크기는 방(가로 약 330·세로 약 190 픽셀)에 비해 너무 크지 않은지 본다.
