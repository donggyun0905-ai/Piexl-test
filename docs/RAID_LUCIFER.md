# 레이드 보스: 루시퍼 (5인 레이드) — 정리안 (검수용)

마지막 수정: 2026-11-09 (한국 시간)
그림: `art/레이드보스/루시퍼/` (13개)

## 0. 그림 번호 (기본공격 모션 `루시퍼 기본공격모션.png`, 왼쪽 열·오른쪽 열 각 7줄, 줄마다 4단계)

| 줄 | 왼쪽 열 | 오른쪽 열 |
| --- | --- | --- |
| 1 | 마법진 (손에 생김) | 초승달 검기 |
| 2 | 어둠 불기둥 (바닥 원 + 빛기둥) | 어둠 화살비 |
| 3 | 별 고리 (궤도 2개) | 날개 |
| 4 | 어둠 화살 (가로로 날아감) | 가시 고리 (머리 위) |
| 5 | X자 | 악마의 불길 (얼굴 있는 불꽃) |
| 6 | 보라 구 | 사슬 묶음 |
| 7 | 소용돌이 (안 씀) | 어둠의 기둥 (위에 고리) |

※ 메모의 "오른쪽 4번째 악마의 불길", "오른쪽 5번째 사슬"은 그림상 **5번째·6번째**라서 위 표대로 잡았습니다. (4번째 = 머리 위 가시 고리)

## 1. 들어가기

- 메인 '이벤트' 창에 **레이드** 버튼 추가 → 레이드 보스 목록(지금은 루시퍼 하나, 나머지 자리는 '준비 중')
- 보스 카드 누르기 → **준비하기**
  - 준비하기 = 기존 협동 방 재사용: 친구 초대(코드·링크), 자동으로 다른 사람 찾기, 최대 5명
  - **AI와 바로 시작** 버튼: 빈 자리를 AI 동료로 채워 즉시 시작 (혼자여도 됨)

## 2. 준비 단계 (전투 전, 각자 진행)

1. **캐릭터 선택** → 그 캐릭터 무기 중 원하는 것 1개 선택
2. 패시브 지급
   - 일반 패시브: 없음
   - 고른 캐릭터의 **전용 패시브 전부 1개씩**
   - **여신의 축복** 지급
   - 원하는 **사용 아이템 2개** 고르기
3. **대장간**: 999원을 받고 대장간 창에서 강화 (남은 돈은 전투에 안 가져감)
4. **성좌의 방들**: 8 성좌 방 중 원하는 방 1곳에 들어가면, 원래 카드 3장 중 **가운데 1장**의 증강을 대가 없이 그냥 받음
5. **마지막 방(단련의 방)**: 단련 점수 30을 받고 단련 창에서 찍기
6. 모두 준비 완료 → 레이드 방 입장 (먼저 끝난 사람은 대기)

## 3. 레이드 방 공통

- 방 크기 = 라스트 보스 방의 2배, 화면 배율 1/2 (멀리 보이게)
- 루시퍼 크기 = 라스트 보스의 2배 이상 (화면에서 약 200칸 높이) · 석화의 기둥·절망의 검도 크게 (약 120칸 높이) · 공격 이펙트도 맵 크기에 맞춰 크게 (2026-11-09 사용자 요청: 맵이 크니 다 크게)
- 체력: 색이 다른 줄 ×99 표시 (기존 라스트 보스 막대 방식). 1페이즈 44,000 / 2페이즈 44,000 (한 줄 ≈ 444)
- "30줄 이하" = 남은 줄이 30줄 이하 (전체의 약 30%)
- 체력은 인원과 상관없이 고정 (AI 동료가 빈자리를 채움)
- **데스 카운트**: 유저마다 10. 죽으면 잠시 뒤 다시 살아나고 1 줄어듦. 10번 죽으면 그 유저는 끝 → 관전. 모두 끝나면 레이드 실패

## 4. 1페이즈 — 여성형 루시퍼 (움직이지 않음)

**석화의 기둥 4개** (체력 각 10,000, `석화의 기둥.png`)
- 처음 자리: 루시퍼 기준 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래 대각선. 루시퍼와 사슬로 연결
- 기둥마다 유저 1명씩 맡아 **매우 느리게** 따라감
- 시작 1분 뒤부터 1분마다 4개가 동시에 아래로 석화의 빔 → 원형 지진파 3번 연속 (멸망의 용 파동처럼, 대시로 넘음)
- 빔을 쏠 때마다 남은 기둥이 있으면 루시퍼에게 **보호막 10,000** (겹치지 않고 10,000으로 다시 채움)

**기둥이 남아 있는 동안 루시퍼 기본 공격**
1. 손에 마법진(왼1) → 유저 발밑에 어둠 불기둥(왼2). 범위 큼, 경고 원 보고 대시로 피함
2. 별 고리(왼3)가 맵 곳곳에 무작위로 생겨 3초 있다 사라짐. 그 사이 몸에 닿으면 터져 피해
3. 가시 고리(오4)가 유저 머리 위를 3~5초(무작위 3·4·5초) 따라다님 → 2번 깜빡임 → 그 자리에 멈춰 내리꽂힘. 깜빡임 보고 대시
4. **기둥 하나 부서질 때마다**: 루시퍼 기절(기본 공격 멈춤) + 초승달 검기(오1) 패턴. 왼쪽·오른쪽·위쪽 중 무작위 방향에서 맵을 거의 덮는 큰 검기, **작은 네모 빈칸**만 안전. 5번 피하면 기절 풀리고 기본 공격 다시 시작
5. **기둥 2개 이상 부서진 뒤**: 어둠의 기둥(오7)이 유저마다 계속 따라다니며 20초마다 내리침. 맞으면 피해 대신 **어둠의 세계**로 이동
   - 어둠의 세계: 치유 -100%, 아이템 사용 불가, 사거리 -50%, 공격 속도 -50%, 이동 속도 -50%
   - 그 안의 몬스터를 다 잡으면 원래 자리로 돌아감

**기둥 4개 다 부서진 뒤**
- 맵이 흔들리고 맵 어딘가에 **흰색 돔** 생김 → 2.5초 뒤 컷신 `기둥4개 부서진 이후 필살기 컷신.gif` 전체 화면
- 끝나면 돔 안에 있던 사람은 피해 없음, 밖에 있던 사람은 **최대 체력 80%** 피해
- 이후 기본 공격에 추가:
  - X자(왼5): 경고 표시 없음. X가 다 그려지기 전에 보고 피함
  - 보라 구(왼6): 경고 없이 생겨 모든 유저를 일정 거리 끌어당긴 뒤 터짐
- **체력 30줄 이하**: 30초마다 악마의 불길 몬스터(오5) 4마리 등장. 어둠 화살(왼4)·어둠 화살비(오2)를 주기적으로 쏨 → 빨리 처치

**1페이즈 체력 0** → 컷신 `페이즈1에서2로 변신.gif` 전체 화면 → 2페이즈

## 5. 2페이즈 — 남성형 루시퍼 (움직이며 공격)

- 기본 공격: 초승달 검기 휘두르기(`루시퍼_페이즈2_공격모션.png`) + 1페이즈 기본 공격 일부

**절망의 검 4개** (체력 각 10,000, `절망의검.png`)
- 유저에게 느리게 다가감. 검이 패턴 색으로 빛나면 그 패턴을 맵 곳곳에 뿌림
- 보스에게 보호막은 안 줌. 대신 주기적으로 **맵 전체 기절 0.5초**
- 검 패턴 (레이드용 맵 잔패턴 그림에서 6개 선정, 빛 색 = 패턴 색)
  1. 빨강 — 붉은 X 사슬: 맵을 가로지르는 X자 사슬 선 (선 경고 뒤 터짐)
  2. 파랑 — 얼음 가시: 땅에서 일직선으로 차례차례 솟는 얼음 결정
  3. 금색 — 빛의 검 비: 경고 원 위로 금빛 검이 떨어짐
  4. 보라 — 보라 유성: 맵 끝에서 대각선으로 날아오는 유성
  5. 초록 — 가시 덩굴: 바닥에 덩굴 장판, 밟으면 느려지고 계속 피해
  6. 진보라 — 땅에서 솟는 손: 유저 발밑에서 손이 솟아 잡으면 잠깐 묶임

**검 4개 다 부서진 뒤**
1. 컷신 `2페이즈_필살기 컷신.gif` (피할 곳 없음)
2. 보스 사라짐 + 화면 어두워짐. 바닥에 큰 원이 차례로 생기고 절망의 검이 떨어짐 → 대시로 연속 회피
3. 다 피하면 5명 전원 **사슬 묶음**(오6). 화면 가운데 큰 화살표 순서(예: ↑↓↓←)를 빨리 눌러야 풀림. 늦으면 보스 기본 공격에 맞음 (기존 사슬 방향키 코드 재사용)
4. 이후 1 대 5: 모든 기본 공격 사용

**체력 30줄 이하**
- 맵 곳곳에 날개(오3) 생김 → 몸으로 닿으면 장착
- 루시퍼가 바닥을 내리쳐 바닥이 꺼짐 → **탄막 비행 모드**로 계속. 날개를 못 단 사람은 떨어져 죽음 (데스 카운트가 남아 있어도 관전)

**2페이즈 체력 0** → 바닥 복구, 날개 사라짐 → 컷신 `피가다해_죽는모습.gif` → 보상 맵

## 6. 보상 맵

- 화려하게 꾸민 방(별빛·보라·금빛 장식, 반짝이는 바닥) 한가운데 **큰 상자**
- 유저들이 때려서 상자 체력을 다 깎으면 열림 → 모두에게 동시에 "축하합니다!" 창 (보상은 아직 없음)

## 7. 만드는 방식 (기술)

- 협동 방·자동 매칭·친구 초대·AI 동료는 기존 `coop/`·`party` 재사용. 레이드 방은 협동 방의 새 '모드'
- 계산은 시드 결정성 유지 (`Math.random` 금지, `rot` 사용). 새 파일: `sim/raidLucifer*`(페이즈·기둥·검·어둠의 세계·날개 탄막 나눠서), 수치는 `LUCIFER_RULES`로 관리자 페이지에서 조정
- 그림: 효과 시트는 검은 바탕이라 칸을 잘라 '더하기' 합성으로 그림. 루시퍼·기둥·검은 검은 바탕을 지워 투명하게 만들고 줄여서 넣음. 컷신 GIF는 압축(크기 줄이기) 후 전체 화면 표시 (그동안 게임은 멈춤)
- 원형 파동 = `bossWaves`, 사슬 화살표 = `bossBinds`, 위험 표시 = `hazards` 재사용
- 글자 한·영·일, 패치 노트, 버전 0.51.0 (새 모드), `docs/MAP.md` 등록
