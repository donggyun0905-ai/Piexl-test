# 캐릭터 그림 만드는 법 (생성 AI → 게임)

> 2026-10-31 정리. 마법사(0.48.269)로 시험한 방식. 그림 규격 전체는 `docs/ART.md`

## 한눈에

1. **GPT** (이미 쓰는 구독): 캐릭터 **설정 그림** 1장 (디자인 확정용)
2. **PixelLab** (한 달 구독, 약 12달러 · 결제 전 공식 가격 확인): 설정 그림을 참고로 **게임용 걷기 시트** (4방향 × 4칸 + 공격)
3. **Claude**: 받은 PNG를 `scripts/art/import_sheet.py`로 128칸 게임 시트로 바꿔 넣고, 게임 화면을 찍어 보여 줌

- 디자인만 먼저 바꾸고 싶으면 1번 그림 하나만 보내도 됨 (마법사처럼 방향별 한 장씩으로 우선 넣을 수 있음. 걷기는 몸만 흔들림)
- 사용자가 할 일: 1·2번 그림 만들기 → **원본 PNG 파일**(화면 캡처 말고 '다운로드')을 채팅에 올리기 → 게임 화면 보고 OK/수정

## 사용자 순서 (캐릭터 하나)

1. 바꿀 캐릭터를 고름 (게임 속 지금 모습·캐릭터 설명을 참고, 모르면 Claude에게 "○○ 설명해줘")
2. GPT에 **프롬프트 A**를 넣어 설정 그림을 만듦 → 마음에 들 때까지 다시 만들기
3. PixelLab에서 새 캐릭터 → 설정 그림을 참고 그림으로 올리고 **프롬프트 B** → 4방향 걷기 애니메이션 생성 → 공격(지팡이·검 휘두르기 등) 애니메이션 생성
4. PNG로 내려받기 (투명 배경 또는 단색 배경, 프레임이 나뉘어 있어도 됨)
5. 채팅에 올리며 "○○ 캐릭터 이걸로 바꿔줘"라고 하면 Claude가 넣고 게임 화면을 찍어 보여 줌
6. 좋으면 다음 캐릭터. 5명 정도 모아서 보내도 됨

## 프롬프트 A (GPT · 설정 그림)

```
픽셀 아트 게임 캐릭터 설정 시트를 만들어 줘.
캐릭터: {이름} — {한 줄 설정. 예: 별빛을 다루는 마법사 소녀}
모습: {머리색·머리 모양 · 눈 색 · 옷(색·소재·장식) · 무기 · 특징 소품}
분위기: {예: 맑고 신비로움 / 거칠고 강인함}
구성: 왼쪽에 큰 전신 그림, 오른쪽에 앞·뒤·옆 모습, 아래에 작은 게임용 캐릭터(2등신, 머리가 큰 귀여운 비율) 4방향.
스타일: 깔끔한 도트, 진한 테두리, 왼쪽 위에서 빛, 단색 검정 배경, 글자 넣지 않기.
다른 게임·작품의 캐릭터를 따라 하지 않은 독창적인 디자인으로.
```

## 프롬프트 B (PixelLab · 게임용 시트)

```
chibi pixel art character, 2-head-tall cute proportions, big head, {모습 요약을 영어로},
128x128 canvas, character centered, feet at bottom, bold dark outline, top-left lighting,
transparent background, consistent design in every frame
```
- 방향: 4방향(앞·뒤·왼쪽·오른쪽) · 동작: 걷기 4칸 · 공격 4칸 (앞 3칸 + 옆 1칸이면 충분)
- 같은 캐릭터를 여러 동작으로 만들 때는 같은 캐릭터(참고 그림)를 계속 씀 → 얼굴·옷이 달라지지 않게

## 체크 (그림을 보내기 전에)

- [ ] 원본 PNG인지 (휴대폰 화면 캡처는 흐려짐)
- [ ] 방향마다 같은 얼굴·옷인지 (다르면 다시 생성)
- [ ] 배경이 투명 또는 한 가지 색인지 (그림자·바닥 무늬 없이)
- [ ] 무기를 들고 있는지 (게임에서 같이 그려짐)
- [ ] 약관: 쓰는 도구가 **상업적 이용**을 허용하는지 (유료 판매·광고 수익 예정)

## Claude 쪽 처리 (참고)

- 원본 조각 → `scripts/art/src/{캐릭터}.png` · 자리 표 → `import_sheet.py`의 `SOURCES`
- 배경 지우기 → 크기 맞추기(앞모습 키 = 116칸) → 또렷하게·색 진하게 → 96색 → 두 칸 테두리 → 128칸 4×4 시트(앞·뒤·옆 걷기, 공격)
- `game/sprites.ts`의 그 캐릭터에 `src: 128` · 게임 크기(32)는 그대로
- 테마 스킨 9 + 승리: `scripts/art/hd_skins.py {캐릭터}`가 자동으로 (흰 옷·푸른 천 → 테마 색, 머리 위 소품, 승리는 금빛 테두리) · 캐릭터마다 머리 자리 `HEAD`만 적으면 됨
  - 옷이 머리카락과 비슷한 색(흰 옷 + 금발 등)이면 옷 색은 조금만 바뀜 → 더 확실히 바꾸려면 그 스킨을 생성 AI로 (같은 캐릭터, 옷만 바꿔 달라고)
- 한정 스킨(범 풍류·여름)은 생성 AI로 따로

## 그림 공장 (OpenAI 그림 API · GitHub Actions)

- 파일: `.github/workflows/art-factory.yml` · `scripts/art/factory.py` · 프롬프트 틀 `scripts/art/factory_prompts.py` (테마 10종 설명 포함)
- **처음 한 번 (사용자)**: 저장소 Settings → Environments → `art-factory` 만들기 → ① Required reviewers에 본인 추가 ② Environment secrets에 `OPENAI_API_KEY` 넣기 (키는 채팅에 붙이지 않음)
- **실행 규칙 (2026-10-31 사용자 지시)**
  1. Claude가 무엇을 몇 장·어떤 품질로 만들지(예상 비용 포함) 먼저 채팅으로 묻고 허락받음
  2. 허락받으면 Claude가 실행 → GitHub에서 사용자가 **승인** 눌러야 실제로 돌아감 (Actions 실행 화면의 Review deployments)
  3. 결과는 `art-factory/{번호}` 브랜치에만 저장 (test·배포와 섞이지 않음)
  4. Claude가 결과 그림을 **모두 채팅에 보여 줌** (원본 + 게임 크기 미리보기) → 사용자가 고른 것만 게임에 넣음 → 게임 화면도 보여 줌
- 입력: 종류(character·skin·effect) · 대상(캐릭터 id·이펙트 이름) · 테마 · 추가 설명 · 장 수(1~4) · 품질(low·medium·high) · 모델 이름
- 이펙트·소품은 한 장만 만들고 움직임(흔들림·회전·크기·빛)은 게임 코드로 붙임
